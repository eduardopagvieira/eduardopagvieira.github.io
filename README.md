# Site pessoal de Eduardo Vieira

Página única em HTML, sem dependências, com os projetos de dados abertos e as frentes de pesquisa.

Para publicar no GitHub Pages, este repositório deve se chamar `eduardopagvieira.github.io`. O site passa a responder nesse endereço. Pages em repositório privado exige plano pago, então o repositório fica público quando o site for ao ar.

Antes de publicar, falta pôr o link do LinkedIn nos dois botões marcados com `href="#contato"` e tornar públicos os repositórios rouanet, consumidor e bndes, para os links de código funcionarem.
